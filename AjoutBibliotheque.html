Ajout Bibliothèque

Import de Bibliothèques





Pour quelle raison est-il nécessaire de référencer les Bibliothèques ?


Il existe de nombreuses Bibliothèque dans Topsolid. D'abord celles incluses par défaut. 

Puis nous pouvons en importer tant que nécessaire, il est aussi possible d'en créer des personnalisées.

Pour chaque nouveau projet, les Bibliothèques de base sont automatiquement incluses.

Pour toutes autres Bibliothèques il faudra les référencer dans le projet.

Une utilisation industrielle peut mener à posséder des dizaines de Bibliothèques.

Le mode de gestion de Topsolid donne une souplesse qui permet d'inclure que ce qui est nécessaire

au projet tout en ayant une base de données qui n'est pas limitée.

Onglet accueil:



  • Importer le pkg de la Bibliothèque, de la même manière qu'un projet "classique".



  • Une fenêtre permet d'aller chercher le pkg dans vos fichiers.

Ici nous importons la Bibliothèque "Symboles MIP MAP",

cependant la méthode est valable pour toutes bibliothèque.



Une nouvelle fenêtre s'ouvre en indiquant le contenu du pkg.



Pour voir toutes les Bibliothèques présentes sur le poste.




La Bibliothèque "Symboles MIP MAP" est bien présente.



IL faut à présent référencer la Bibliothèque dans le projet.


  • Dans la fenêtre gestion de projets.


sur le + devant


On peut voir que la Bibliothèque "Symboles MIP MAP" n'est pas présente dans le projet.



  • sur




  • Sélectionner la Bibliothèque à référencer.






La Bibliothèque est à présent référencée dans le projet.
