3) Définir un document principal.

1) Fermer les projets ouvert.


En première lieu il conviens de fermer tous les documents récent, appartenant aux personnes ayant utilisé le poste avant vous.

  sur l'icône TopSolid.




  • Fichier / Fermer tout 




2) Créer un Nouveau projet.


  sur l'icône TopSolid.



  • Fichier / Nouveau projet.... 




  • Entrer le nom du projet.  Valider








Remarque: 

Lorsqu'un astérisque ( )est présent près d'un champ de saisie, cela indique qu'une information est manquante pour valider la fonction.



Le projet est crée et une fenêtre s'ouvre à droite de la zone graphique.








3) Définir un document principal.




Choisir le document le plus représentatif du projet


  •  sur le document le plus représentatif

Autre // Document principal





Cette manipulation permet d'obtenir un aperçu du document principal dans la fenêtre (liste) de projets.






4) Sauvegarde de projet. (Export de projet ou de bibliothèques).






  • Dans la fenêtre gestion de projets



  • Sur le nom du projet Mettre à jour...















  • Valider













  • Dans la fenêtre gestion de projets
  • Sur le nom du projet Import / Export

Exporter Paquet...

























Une fenêtre d'explorateur s'ouvre. Sauvegarder le projet dans vos documents et dans W étudiant dosssup.






  • Vérifier que le projet est présent dans le dossier de sauvegarde



Le projet à une extension .TOPPKG.







5) Choix du répertoire de sauvegarde par défaut.

   

  sur l'icône TopSolid.





  • PDM / Chemin d'export par défaut...







6) Importer un projet.


  sur l'icône TopSolid.



  • Fichier / Importer projet.... 



















  • Répondre par Oui.... 















  • Valider    












La fenêtre projet s'ouvre à droite de la zone graphique.









7) Rechercher un projet sur le poste.


La page d’accueil n'affiche que les projets récent. La liste de tous les projets sauvegardés sur le poste se trouve en passant par le menu fichier.


  sur l'icône TopSolid.



  • Fichier / Projets.... 





  • Sur le nom du projet à ouvrir.




  • Valider    





La fenêtre projet s'ouvre à droite de la zone graphique.
