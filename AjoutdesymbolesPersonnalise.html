Création de symboles personnalisé










Dans le fenêtre gestion de projet

  • sur le nom du projet /






  • Dessiner la forme désirée dans une Esquisse.
  • Il est nécessaire de centrer le dessin sur l'origine de l'esquisse. C'est cette origine qui sert de point d'insertion pour le modèle



Le modèle 2D n'accepte pas les profils qui s'entrecroisent. 

Il est parfois nécessaire de créer plusieurs esquisses.

Coter les éléments. Les cotes seront masquées lorsque le symbole seras inséré dans les contrats de phases.

Ensemble de définition


  • Outils / Ensembles / Ensemble de définition


  • Sélectionner l'esquisse.

Ensemble



  • Outils / Ensembles / Ensemble



  • Sélectionner l'esquisse.


S'il y a plusieurs esquisse, sélectionner toutes les esquisses.




Dans la fenêtre Entités, Ensembles, vérifier que les esquisses soient bien sélectionnées.
